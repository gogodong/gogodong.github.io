Azure Student Plan 申请指南

我的情况是，已经通过了Github的学生包验证，然后申请Azure Student Plan。

认证步骤

  1. 将你的微软账户邮箱与GitHub账户关联；
  2. 访问Azure for Students页面；
  3. 使用github账户登录微软Azure；
  4. 系统会自动验证你的学生身份。

这样认证非常快，比自己提交学生证明要方便很多。
